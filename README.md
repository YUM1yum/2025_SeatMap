SeatMap

SeatMap은 강의실에 가기 전에 빈자리를 확인할 수 있도록 만든 2025년 공과대학 학술대회 프로젝트입니다. 대상 공간은 명신관 518호입니다. Python 서버는 카메라 영상에서 좌석의 점유 여부를 판정하고, Flutter 앱에는 테이블 6개와 좌석 30개의 배치도가 구현되어 있습니다.

현재 저장소만으로 바로 확인할 수 있는 부분은 예제 서버가 보내는 좌석 데이터입니다. 실제 영상 추론에는 학습 가중치와 카메라 스트림이 필요하고, 앱에 추론 결과를 표시하려면 서버와 앱의 메시지 형식을 맞춰야 합니다.

1. 카메라 없이 좌석 데이터 받아보기

Python 3.12와 websockets 16.0에서 확인했습니다. 두 터미널에서 같은 Python 환경을 사용하세요.

터미널 1 · 저장소 최상위 폴더에서 예제 서버를 시작합니다.

python -m pip install websockets==16.0
python server/Websocket_server.py

터미널 2 · 서버에 접속해 첫 메시지를 확인합니다.

python -m websockets ws://127.0.0.1:8000

접속하면 즉시 JSON 한 건이 도착합니다. total_seats는 30, occupied는 0이고, seats에는 1번부터 30번까지 모두 occupied: false로 들어 있습니다. 예제 서버는 같은 값을 60초마다 다시 보냅니다.

2. 영상에서 빈자리를 판정하는 방법

좌석 추론 서버는 RTSP 영상을 읽고 좌석 좌표 파일에 지정된 영역을 잘라 YOLO에 입력합니다. 사람이 잠깐 가려져도 자리가 바로 비었다고 표시되지 않도록, 점유로 바꾸려면 추론 프레임 3회 연속 검출, 빈자리로 바꾸려면 10회 연속 미검출을 요구합니다. 서버는 좌석별 판정 결과를 WebSocket 포트 8765로 60초마다 보냅니다.

실제 카메라로 실행하려면 다음을 준비하세요.

518호 학습 노트북에서 사용하는 empty·occupied 모델의 가중치를 server/best_seatmap_model.pt에 둡니다. 저장소에는 학습 노트북과 좌석 좌표가 들어 있고, 학습 데이터와 가중치는 별도로 준비해야 합니다.

Pipelines.py의 RTSP_URL을 사용할 카메라 스트림 주소로 바꾸고, 영상에서 각 좌석의 위치가 seat_rois.json과 맞는지 확인합니다. 화면 표시가 없는 환경에서는 SHOW_WINDOWS = False로 설정합니다.

아래 명령을 저장소 최상위 폴더에서 실행합니다. 서버는 현재 작업 폴더를 기준으로 가중치와 좌석 좌표를 읽습니다.

cd server
python -m pip install ultralytics opencv-python numpy websockets
python Pipelines.py

3. 앱과 서버를 연결할 때 확인할 부분

앱에서 명신관 518호를 누르면 강의실 지도가 ws://10.0.2.2:8765에 접속하도록 좌석 화면을 엽니다. 이 주소는 Android 에뮬레이터에서 개발 PC에 접속할 때 쓰는 주소입니다. 현재 서버마다 메시지 구조와 좌석 ID 표기가 다릅니다.

좌석 화면은 최상위 키를 모두 정수로 읽습니다. 따라서 서버 응답의 timestamp나 room에서 파싱이 실패합니다. 첫 연동 목표는 예제 서버에서 1번 좌석만 점유로 보냈을 때 앱의 1번 좌석만 빨간색으로 바뀌는 것입니다. 이때 사용할 메시지 형식과 좌석 ID를 먼저 정하면 카메라 없이도 화면까지 검증할 수 있습니다. 실시간 데이터가 오기 전에도 현재 화면은 모든 좌석을 빈자리로 그리므로, 첫 수신 전에는 ‘연결 대기 중’ 상태를 따로 표시할 필요가 있습니다.

Flutter 소스와 의존성은 front/에 있습니다. pubspec.yaml은 Dart ^3.9.0을 지정합니다. Android로 실행하려면 저장소에서 빠진 Gradle 빌드 파일과 MainActivity를 복원해야 합니다. 좌석 화면에서 참조하는 assets/icons/network.svg도 복원해 등록하거나 기존 아이콘으로 교체해야 합니다.
